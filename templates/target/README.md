# Target — Photographer (recréation)

Recréation fidèle du template photographe « Target » (thème sombre, hero motion-blur,
services, marquee collaborations, projets, beyond the frame, témoignages, FAQ accordéon,
galerie masonry, footer). React + TS + Vite + Tailwind + Framer Motion + Lucide.
Polices Geist + Inter. Animations : reveals au scroll, marquee CSS, accordéon, hover.

## Démarrer
```bash
npm install && npm run dev
npm run build
```
Photos bundlées (loremflickr, libres) — swappables.
